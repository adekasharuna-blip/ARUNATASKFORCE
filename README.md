# studyaruna

Halo, aku ARUNA. Teman belajar terbaikmu.

studyaruna is a smart task management web application designed to help users optimize their daily schedules based on their current mental energy and available time. 

## 🚀 Features
* **Mental State Check-in:** Users start by logging their current mental energy level.
* **Smart Task Input:** Easily add tasks, deadlines, and workload estimations.
* **Time Management:** Input available working hours to ensure realistic planning.
* **Optimized Daily Plan:** The app generates a customized schedule, prioritizing tasks based on deadlines and the user's cognitive capacity for the day.

## 🛠️ Built With
* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
